Configuration

The PagefindIndexOptions record controls how the index is built. Pass it to the PagefindIndex constructor.

Language

Set the Language property to a BCP-47 language tag (e.g. "en"). This controls which wasm.*.pagefind file the entry JSON references.

IncludeCharacters

Additional Unicode characters to keep during tokenisation. By default only letters and digits are kept. Add characters such as +, #, or @ if they appear in searchable terms in your content.

Weighted Segments

Provide WeightedSegments on each record to boost heading terms. Suggested weights: H1 = 7, H2 = 4, H3 = 3, body = 1.
