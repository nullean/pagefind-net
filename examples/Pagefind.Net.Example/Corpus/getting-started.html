Getting Started

Welcome to the pagefind-net example. This guide shows you how to install and configure the library so you can add static full-text search to your .NET documentation site.

Installation

Install the Pagefind.Net NuGet package into your project: 

dotnet add package Pagefind.Net

Quickstart

Create a PagefindIndex, add records, and call WriteAsync: 


var index = new PagefindIndex();
index.AddRecord(new PagefindRecord { Url = "/guide/", Title = "Guide", Content = "…" });
await index.WriteAsync(outputDir);

Frontend Runtime

pagefind-net writes only the index data files. You must supply pagefind.js and the wasm.*.pagefind files from the pagefind npm package.
