API Reference

Complete reference for all public types in the Pagefind.Net library.

PagefindIndex

The main entry point. Create one per build, call AddRecord for each document, then WriteAsync to flush the index to disk.

PagefindTargetVersion is a constant string matching the Pagefind release version whose binary format this library targets.

PagefindRecord

Represents a single indexable document. Required fields: Url, Title, Content. Optional: WeightedSegments, Anchors, Meta.

WeightedSegment

A plain-text string with a relative search weight. Terms in higher-weight segments receive larger weight markers in the CBOR index, boosting BM25 scores.

PagefindAnchor

A heading anchor within a page. The Pagefind JS runtime uses anchors to generate sub-results linking directly to specific headings (e.g. /guide/#installation).
